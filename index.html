Input data

Optional uploads

Join a separate lab table using sample_id. Upload a polygon Shapefile ZIP or GeoJSON to use your own boundary.

Mapping parameters

BSWM inputs use % for N and OM, ppm for P and K, and a 1:1 ratio for pH. All-parameter runs auto-fit each variogram and use the BSWM classes for each parameter. Choose one parameter to set its units, thresholds, or manual fit. Leave blank to use the BSWM guide.
